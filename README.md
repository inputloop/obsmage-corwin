# obsmage-corwin

Corwin's own OBS recipe for Avalon and Giza, built on [inputloop/obsmage](https://github.com/inputloop/obsmage),
whose README explains the recipe format and its tools. Start with `RECIPE.md`.

- `RECIPE.md`: the recipe, and how this repository is kept.
- `STAGES.md` and `SCENES.md`: the stages and scenes.
- `TEST-CARD.md`: the test card, obsmage on Avalon.
- `hosts/` (avalon, giza), `atoms/` and `journal/`.
